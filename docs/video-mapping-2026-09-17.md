# 영상·토론 범위 정정 — 2026-09-17

사용자 확정: 영상 원본 1~4번이 아니라 2~5번을 사용한다. 변경 범위는 영상·토론이며 이론·퀴즈는 유지한다.

| 수업 차시 | 이론·퀴즈 유지 | 영상 원본 번호 | 영상 내용 | 토론 주제 1 / 2 / 3 |
|---|---|---|---|---|
| 1 | 금융과 소득의 이해 | 2 | 저축 목표와 계획 | 목표 정하기 / 역산하기 / 상품 고르기 |
| 2 | 티끌 모아 태산 | 3 | 보험과 위험 대비 | 현재 점검 / 생애 설계 / 우선순위 정하기 |
| 3 | 미래 위험으로부터 보호 | 4 | 투자 성향과 자산 배분 | 진단 / 자산 배분 / 실행 문장 |
| 4 | 하이리스크, 하이리턴 | 5 | 노후 생활비와 준비 | 기초적 노후 생활 / 은퇴 후 40년 / 대책 생각하기 |

- 원본 1번 금융사기 영상은 영상·토론 연결에서 제외한다. 이론의 금융사기 설명과 퀴즈는 삭제하지 않는다.
- 5번 영상 토론 주제는 원본 영상 문서 9쪽 이미지와 교육 PDF 50쪽을 대조했다. 조별 발표 문구만 기존 개인 참여 운영에 맞춘다.
- 기존 financial_1~financial_4 / videoId 0~3 / 저장 차시 1~4는 그대로다. 원본 번호와 수업 차시를 혼동하지 않는다.
- 영상·토론 화면은 영상 제목을 표시하고, 이론·퀴즈 화면은 기존 차시 제목을 표시한다.
- Node와 AI의 영상 원문·토론 주제를 동일하게 변경한다. AI에 전달하는 이론 자료는 원래 차시 자료 그대로다. 공통 지침에 이론과 영상 주제가 다를 수 있음을 명시한다.
- 영상 파일은 아직 미수령이다. VITE_FINANCIAL_VIDEO_1~4는 수업 차시 기준이며 각각 원본 2·3·4·5번 영상 URL을 넣는다. 키를 2~5로 옮기지 않는다.
- 3·4차시 퀴즈 미수령 상태, 4축 기준, 기존 디자인, 교사의 수동 토론 종료 방식은 유지한다.

이번 문서가 이전 문서의 영상 1~4번 및 5번 제외 표기보다 우선한다.
