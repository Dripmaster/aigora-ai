## 유지한 변경

- 금융 4축, 발언 근거에 따른 평가, 실패를 평가불가로 표시하는 처리.
- 기존 디자인·로봇·아바타·케이크와 5/9초 결과 연출. 무작위 가짜 결과는 복원하지 않음.
- 승인된 교사 인증, 학생/교사 세션 분리, 학생 이론 화면 및 교사의 퀴즈 단계 전환.
- 영상은 기존 교사 화면 방식. 게임·STT·조 편성 및 검색/RAG를 다시 넣지 않음.
- 원본의 최근 10개 대화 전달 유지. 개인 @아이고라 Q&A가 기록되지 않는 구조는 CJ에도 있었으므로 이번 전환의 새 기록 누락으로 분류하지 않음.
- 타이머의 주기적 리셋 및 자동 종료 없는 동작도 CJ 때 의도한 방식. 자동 종료를 임의 복원하지 않음.

## 검증

- 웹/Node 테스트 32개 통과, production build 통과.
- AI unittest 33개 통과. API 형식 회귀는 수정 전 500을 재현하고 수정 후 통과.
- 1920×1080, 1280×800 로컬 브라우저에서 질문 본문·입력창·토론 방법 안내 확인.
- 로컬 실제 Socket.IO 서버에서 교사 다음/이전 주제 선택 → 학생 제목 갱신 확인. 교사 로그인 확인은 UI 검증용 로컬 응답으로 대체했으므로 운영 인증 테스트라는 뜻은 아님.
- 4차시 슬라이드를 마지막까지 넘겨 63쪽 이미지가 실제 로딩됨을 확인.
- OpenAI 실제 호출은 가상 학생 발언만 사용. 운영 수업 기록에 쓰지 않음.
- 생성 예시: `tmp/quality-restoration/live-before.json`, `live-after.json`. 재현 스크립트: `scripts/quality_examples.py`.
- 독려의 이전 검증: `tmp/encouragement-quality-20260919*.json`. 각 단계 기본 문구 6회 연속 비중복 테스트 통과. 생성 문장 의미의 완전한 비중복을 보장하는 것은 아님.

## 실제 AI 응답에서 남은 한계 — 완료로 처리하지 않음

- 최종 개인 피드백에는 월 10만원 × 12개월 = 120만원, 목표 300만원 대비 180만원 부족이라는 실제 계산이 포함됐다. 이전의 일반적인 ‘구체적으로 계획하세요’ 수준에서 개선됐지만 추가 행동은 여전히 일반적인 표현이 나올 수 있다.
- 중간 Q&A 생성에서는 월 가능액 10만원을 초과하는 12.5만원/20만원 계획 제안 및 잘못된 계산이 관찰됐다. 계산 순서와 제약 확인 지침을 보완한 최종 예시는 필요한 월 25만원·월 부족액 15만원을 맞게 설명했다. 다만 고정 예산에 맞는 기간·목표 대안을 충분히 제시하지 않아 금융 조언 정확도 검증 완료로 볼 수 없다.
- 전체 총평은 여전히 이름을 언급하는 경우가 있고 일부 문장은 발언 요약에 가깝다. 이름 제외 지침 준수와 구체성은 추가 검증 대상.
- 후속 질문 모델은 최근에 의미 있는 의견을 낸 학생에게도 질문을 생성했다. 원래 개입 억제 지침은 남아 있지만 모델 준수가 불완전하다. 모든 반복 질문 문제가 해결됐다고 볼 수 없다.
- 독려의 질문 관점은 다양해졌으나 칭찬·마무리 표현은 유사할 수 있다.

따라서 **구조·형식·UI 검증 통과와 실제 생성 품질 전체의 승인 완료를 구분한다.** 모델 변경이나 새로운 검색·계산 기능은 추가하지 않았다.

## 별도 남은 확정 작업

1. 수업 매핑: 1차시 영상·토론 없음, 2차시 저축, 3차시 보험+노후(두 활동), 4차시 투자. 현재는 1~4차시에 활동 하나씩인 연결이 남아 있다. 회차·영상·결과 연결을 함께 바꾸고 AI 자료와 공통 흐름 지침도 맞춰야 한다.
2. 교사 이론 슬라이드 한 장씩 넘김의 학생 동기화. 현재 퀴즈 등 단계 전환 동기화와는 별개다.
3. 타이머 표시를 어떻게 정리할지, 신용카드 서답형 입력을 어떻게 다룰지의 피드백 대응.
4. 위 실제 생성 품질 한계 보완 및 운영 배포 후 확인. 이번 작업을 전체 피드백 대응이나 운영 반영 완료로 안내하지 않는다.
