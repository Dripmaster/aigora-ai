# 금융교육 AI 자료·API 현재 상태 — 2026-09-15

9월 20일 수업 범위에 맞춰 추가했던 교재 검색 기능을 제거했다. 차시별로 고정된 수업 자료·시나리오와 금융 4축 프롬프트를 사용한다. 교재 PDF를 전달받았다는 사실이 새 기능 추가 요구는 아니었으며, 검색 품질 검수는 이번 수업의 남은 작업에서 제외한다.

## 제거한 내용

- 질문·답변·발언 분류 요청에서 교재 키워드 검색 및 검색 결과 삽입 제거.
- 검색 모듈, 생성 스크립트, 생성 JSON 인덱스와 전용 테스트 제거.
- health 및 Node/AI 교육 데이터의 인덱스 참조 제거. 배포 시 검색 인덱스가 필요하지 않다.
- 별도 벡터 DB·임베딩·인터넷 검색은 사용하지 않는다. 대신 PDF 전체를 프롬프트에 넣는 변경도 하지 않았다.

원본 교재 PDF 6개 271쪽과 수령 기록·추출 텍스트는 로컬 원본/자료 보관 위치에 보존했다. 교재의 자동 검색이나 실행 시 주입은 없다.

## 유지한 내용

- `educational_content.json`의 차시별 고정 이론 자료와 시나리오 1~4, 토론 주제 12개.
- 질문·답변·참여 안내·분류·개인 평가·전체 총평·요약의 금융교육 프롬프트.
- 금융이해 / 위험인식 / 계획성 / 실천의지. 세부 점수 구간과 예시는 홍선생님 검수 전 초안.
- 입력 검증, 생성 실패/평가불가 표시, 외부 호출 타임아웃, 동시 처리 및 대상 학생 발언 보존 수정.
- 기존 모델 `gpt-4o-mini`, Node 연동을 위한 기존 API 응답 키.

## 검증 및 남은 일

검색 제거 후 `.venv-financial/bin/python -m unittest discover -s tests -p 'test_financial*.py'` 30개 통과. 이전 34개에서 검색 전용 4개를 제거했고 API 검증은 고정 자료 사용 방식으로 수정했다. 모델 호출 경계는 대체하여 검사했다.

이전 실제 API 점검은 `credit_balance_exhausted` / `insufficient_quota`로 실패했다. 이번 작업에서는 실제 모델 요청을 재시도하지 않았다. 정상 호출 및 프롬프트 결과 검수는 크레딧 복구 후 필요하다.

복구 후 로컬 점검 명령:

```sh
.venv-financial/bin/python scripts/smoke_financial_api.py --live --output docs/api-live-smoke-recheck.json
```

가상 발언으로 최대 9개 API를 확인하며 첫 분류가 평가불가면 후속 호출을 중단한다. HTTP 200과 정상 평가/답변은 구분한다. 실제 모델 품질·MySQL 저장·20명 리허설은 별도 검증 대상이다.

후속 서버 구성에서 이 AI 작업본을 EC2의 전용 경로에 배치해 127.0.0.1:8100에서 실행했다. 실제 모델 호출은 하지 않았다. Git 커밋·push 및 프런트 공개 배포는 하지 않았다.
